# Rewrite a Local Commit Stack

Read and follow the first available skill entrypoint in this order:

1. `.agents/skills/repo-shared-rewrite-local-commit-stack/SKILL.md` in the
   current repository.
2. `~/.agents/skills/repo-shared-rewrite-local-commit-stack/SKILL.md` in the
   home directory.

Prefer the repository-local entrypoint when both exist. If neither exists, stop
before any history-changing command. Do not use a copy found at any other path.
