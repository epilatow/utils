# Development Status Report

Read and follow the first available skill entrypoint in this order:

1. `.agents/skills/repo-shared-development-status-report/SKILL.md` in the
   current repository.
2. `~/.agents/skills/repo-shared-development-status-report/SKILL.md` in the
   home directory.

Prefer the repository-local entrypoint when both exist. If neither exists,
follow the repository's directly loaded status-report instructions. Do not use
a copy found at any other path.
