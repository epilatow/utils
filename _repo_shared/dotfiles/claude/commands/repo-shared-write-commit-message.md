# Write or Validate a Commit Message

Read and follow the first available skill entrypoint in this order:

1. `.agents/skills/repo-shared-write-commit-message/SKILL.md` in the current
   repository.
2. `~/.agents/skills/repo-shared-write-commit-message/SKILL.md` in the home
   directory.

Prefer the repository-local entrypoint when both exist. If neither exists, use
the repository's directly loaded commit-message instructions. Do not use a copy
found at any other path.
