# Audit a Committed Change

Read and follow the first available skill entrypoint in this order:

1. `.agents/skills/repo-shared-audit-committed-change/SKILL.md` in the current
   repository.
2. `~/.agents/skills/repo-shared-audit-committed-change/SKILL.md` in the home
   directory.

Prefer the repository-local entrypoint when both exist. If neither exists,
report the completeness-audit step as blocked. Do not use a copy found at any
other path.
